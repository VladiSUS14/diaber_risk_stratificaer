# Diabetes Risk Stratifier

Программный модуль для стратификации рисков осложнений сахарного диабета у детей с использованием методов машинного обучения.

Проект разработан в рамках выпускной квалификационной работы. Приложение предназначено для исследовательской оценки осложнений сахарного диабета на основе клинико-лабораторных данных пациента.

## 1. Назначение проекта

Программный модуль позволяет рассчитывать вероятность наличия или признаков риска хронических осложнений сахарного диабета у детей.

В текущей версии реализованы две модели:

1. **Диабетическая нефропатия** — основная модель.
2. **Диабетическая ретинопатия / ангиопатия** — экспериментальная модель.

Модель нефропатии оценивает признаки риска поражения почек на основе клинико-лабораторных данных пациента.

Модель ретинопатии / ангиопатии оценивает вероятность наличия диабетической ретинопатии / ангиопатии. Согласно медицинскому уточнению, столбец `Ангиопатия` в исходных данных отражает уже выявленное хроническое осложнение, соответствующее диабетической ретинопатии / ангиопатии.

## 2. Важное ограничение

Приложение является исследовательским прототипом и не является медицинским изделием.

Результаты работы программы:

* не являются медицинским диагнозом;
* не заменяют консультацию врача;
* должны интерпретироваться специалистом с учетом полной клинической картины;
* требуют дальнейшей проверки на расширенном наборе медицинских данных.

Особенно осторожно следует интерпретировать результат модели ретинопатии / ангиопатии, так как она имеет статус экспериментальной из-за ограниченного объема выборки.

## 3. Реализованные функции

Приложение поддерживает два режима работы:

1. **Ввод одного пациента вручную**

   * врач или пользователь вводит показатели пациента через веб-интерфейс;
   * программа рассчитывает риск нефропатии и ретинопатии / ангиопатии;
   * отображается вероятность, уровень риска, решение модели и краткая расшифровка факторов риска.

2. **Загрузка файла с пациентами**

   * поддерживаются форматы Excel и CSV;
   * программа рассчитывает риски для группы пациентов;
   * результат можно скачать в Excel или CSV.

## 4. Используемые осложнения

### 4.1. Диабетическая нефропатия

Целевая переменная `nephropathy_risk` формируется на основе лабораторных признаков риска поражения почек.

Риск нефропатии считается выявленным, если выполняется хотя бы одно из условий:

* `ACR >= 3 мг/ммоль`;
* `Альбуминурия >= 30 мг/л`;
* `СКФ < 60 мл/мин/1,73 м²`.

После медицинского уточнения показатель HbA1c был исключен из входных признаков модели нефропатии. При этом HbA1c сохраняется в интерфейсе и используется в текстовой расшифровке как общий показатель контроля сахарного диабета.

### 4.2. Диабетическая ретинопатия / ангиопатия

Целевая переменная `angiopathy_risk` формируется на основе признака `Ангиопатия`.

Если у пациента ангиопатия была отмечена хотя бы на одном визите, то итоговый признак считается положительным. Это связано с тем, что хроническое осложнение, выявленное однажды, сохраняется в анамнезе пациента, даже если в дальнейшем оно не прогрессирует.

Модель ретинопатии / ангиопатии является экспериментальной, так как качество модели ограничено малым объемом выборки.

## 7. Описание основных файлов

### `app/streamlit_app.py`

Основной файл пользовательского интерфейса.

Реализует:

* ручной ввод данных одного пациента;
* загрузку Excel/CSV-файла;
* отображение результатов стратификации риска;
* скачивание результатов в Excel и CSV;
* предупреждение о том, что результат не является диагнозом.

### `src/preprocessing.py`

Модуль предобработки исходных данных.

Выполняет:

* загрузку исходного Excel-файла;
* удаление технических пустых столбцов;
* замену пропусков на `NaN`;
* преобразование дат;
* преобразование числовых показателей;
* исправление некорректных значений;
* сохранение очищенной таблицы `cleaned_data.csv`.

### `src/feature_engineering.py`

Модуль формирования обучающей выборки.

Выполняет:

* агрегацию данных по пациентам;
* переход от структуры «одна строка — один визит» к структуре «одна строка — один пациент»;
* расчет агрегированных признаков;
* формирование целевой переменной `nephropathy_risk`;
* формирование целевой переменной `angiopathy_risk`;
* сохранение итогового датасета `model_dataset.csv`.

### `src/predict.py`

Модуль применения обученных моделей.

Выполняет:

* загрузку модели нефропатии;
* загрузку модели ретинопатии / ангиопатии;
* подготовку входных признаков;
* расчет вероятности по каждому осложнению;
* перевод вероятности в уровень риска;
* формирование итогового результата для интерфейса.

### `src/risk_interpretation.py`

Модуль текстовой интерпретации факторов риска.

Формирует краткую расшифровку по введенным данным:

* HbA1c выше целевого уровня;
* длительный стаж сахарного диабета;
* повышенное артериальное давление;
* повышенные процентили САД/ДАД;
* нарушения липидного профиля;
* повышенный ACR;
* повышенная альбуминурия;
* сниженная СКФ;
* наличие кетоацидоза, катаракты, полинейропатии, стеатоза, липодистрофий.

## 8. Установка проекта на Windows

### 8.1. Автоматическая установка

Для установки зависимостей запустите файл:

```text
install.bat
```

Файл создает виртуальное окружение `.venv` и устанавливает необходимые библиотеки из `requirements.txt`.

### 8.2. Ручная установка

Если автоматическая установка не используется, выполните команды в терминале из корня проекта:

```powershell
python -m venv .venv
```

Затем установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 11. Режим ручного ввода

В режиме ручного ввода необходимо заполнить известные показатели пациента.

### Основные данные

* возраст;
* пол;
* стаж сахарного диабета;
* HbA1c.

### Лабораторные показатели

* количество гипогликемий за год;
* ЛПНП;
* ЛПВП;
* триглицериды;
* общий холестерин;
* ACR;
* альбуминурия;
* СКФ.

### Артериальное давление

В интерфейсе предусмотрены четыре поля:

* САД;
* ДАД;
* процентиль САД;
* процентиль ДАД.

Для детей артериальное давление рекомендуется оценивать по процентилям с учетом возраста, пола и роста. Поэтому врач может самостоятельно указать процентили САД и ДАД.

Если процентили не указаны, приложение использует САД и ДАД только для общей подсказки в расшифровке.

### Осложнения и состояния

В ручном вводе используются следующие поля:

* терапия;
* кетоацидоз;
* катаракта;
* полинейропатия;
* стеатоз;
* липодистрофии.

Поле `Ангиопатия` в ручном вводе не используется, так как ангиопатия / ретинопатия является прогнозируемым осложнением.

## 12. Ввод десятичных чисел

В текстовых полях можно использовать как точку, так и запятую.

Например, оба варианта будут обработаны корректно:

```text
3.1
3,1
```

Если поле оставить пустым, значение будет считаться пропущенным. В этом случае модель выполнит расчет на основе доступных данных, а приложение покажет предупреждение о неполноте информации.

## 14. Режим загрузки файла

В режиме загрузки файла можно загрузить Excel или CSV.

Поддерживаются три типа структуры файла:

### 14.1. Файл уже содержит признаки модели

Если файл содержит признаки в формате обучающего датасета, приложение использует их напрямую.

### 14.2. Файл содержит исходные визиты пациентов

Если файл имеет структуру исходной таблицы с несколькими визитами одного пациента, приложение:

1. очищает данные;
2. агрегирует визиты по пациентам;
3. рассчитывает риски осложнений.

Для такого файла должны быть столбцы:

```text
№
Дата визита
Возраст
Пол
Стаж СД
HbA1c
```

### 14.3. Файл содержит одну строку на пациента

Если файл содержит одну строку на пациента, минимально необходимы столбцы:

```text
Возраст
Пол
Стаж СД
HbA1c
```

Дополнительные показатели могут быть заполнены при наличии данных.

## 15. Выгрузка результатов

После расчета по файлу приложение формирует итоговую таблицу.

В таблице отображаются:

* идентификатор пациента;
* вероятность риска нефропатии;
* уровень риска нефропатии;
* решение модели по нефропатии;
* вероятность ретинопатии / ангиопатии;
* уровень риска ретинопатии / ангиопатии;
* решение модели по ретинопатии / ангиопатии;
* краткая расшифровка факторов риска.

Результаты можно скачать в форматах:

* Excel;
* CSV.

Рекомендуется использовать Excel, так как он лучше подходит для просмотра таблиц с русскими заголовками и длинной расшифровкой факторов риска.

## 16. Интерпретация результатов

Для каждого осложнения приложение выводит:

1. **Расчетную вероятность риска**
2. **Уровень риска**
3. **Решение модели**

Уровни риска определяются так:

```text
0–29,9% — низкий риск
30–69,9% — умеренный риск
70–100% — высокий риск
```

Бинарное решение модели формируется на основе порога классификации:

```text
Признаки риска выявлены
Признаки риска не выявлены
```

Для модели нефропатии используется порог `0.5`.

Для модели ретинопатии / ангиопатии используется порог `0.5`.

## 17. Метрики моделей

### 17.1. Модель диабетической нефропатии

Финальная модель:

```text
Random Forest Tuned no HbA1c
```

HbA1c исключен из входных признаков модели нефропатии по рекомендации медицинского специалиста.

Метрики на тестовой выборке:

```text
accuracy = 0.792
balanced_accuracy = 0.721
precision = 0.500
recall = 0.600
f1_score = 0.545
roc_auc = 0.632
```

### 17.2. Модель диабетической ретинопатии / ангиопатии

Финальная модель:

```text
Random Forest
```

Модель имеет экспериментальный статус.

Метрики на тестовой выборке:

```text
accuracy = 0.800
balanced_accuracy = 0.640
precision = 0.667
recall = 0.333
f1_score = 0.444
roc_auc = 0.566
```

Низкое значение recall связано с малым количеством пациентов положительного класса и ограниченным объемом исходной выборки.

## 18. Медицинская логика проекта

### 18.1. Нефропатия

В рамках проекта риск диабетической нефропатии формируется по следующим признакам:

```text
ACR >= 3 мг/ммоль
или
Альбуминурия >= 30 мг/л
или
СКФ < 60 мл/мин/1,73 м²
```

ACR в исходной таблице указан в мг/ммоль.

Альбуминурия в исходной таблице соответствует микроальбумину в моче и указана в мг/л.

### 18.2. Ретинопатия / ангиопатия

В исходной таблице признак `Ангиопатия` означает наличие диабетической ретинопатии / ангиопатии.

Если осложнение было отмечено хотя бы на одном визите, оно считается выявленным для пациента.
